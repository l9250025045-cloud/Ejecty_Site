# Ejecty — Лендинг

Посадочная страница приложения **Ejecty** — чистит динамики, выгоняет воду и пыль,
тестирует наушники и колонки, измеряет уровень шума и генерирует частоты.
Прямо с телефона, без инструментов.

Страница — близкая к пикселю реализация макета Ejecty из Figma, собранная как
лёгкий статический сайт (без сборки и фреймворков) на чистых HTML, CSS и JavaScript.

---

## ✨ Секции

- **Шапка** — залипающее меню со стеклянным размытием и кнопкой «Get the App».
- **Hero** — крупный заголовок «Clean Your Speakers in Seconds» с 3D‑блобами,
  смайлом, взрывом, паучком и каплями воды, которые слегка следуют за курсором.
- **Бегущая строка** — бесконечная лента «Ejecty».
- **Capabilities** — горизонтальная карусель из четырёх экранов приложения
  (Water Eject, dB Meter, Device Test, Frequency Generator) со стеклянными
  карточками‑описаниями, стрелками и перспективной сеткой на фоне.
- **Маркиза паучков** — бесконечная лента милых чёрных паучков.
- **CTA** — «Ready for Perfect Sound?» с кнопкой загрузки, рейтингами и ссылками
  на правовые страницы.

**Правовые страницы**
- **Terms of Use** и **Privacy Policy** — отдельные страницы в едином стиле с
  лендингом (общая шапка, градиентный фон, типографика Manrope).

## 🧩 Интерактив (`js/main.js`)

- Бесконечные ленты (бренд + паучки), собираемые из повторяющихся элементов.
- Параллакс декораций Hero, следящих за курсором.
- Плавное появление карточек и секций при прокрутке (IntersectionObserver).
- Усиление тени шапки после начала прокрутки.

## 🗂 Структура

```
index.html            — лендинг
terms-of-use.html     — Terms of Use
privacy-policy.html   — Privacy Policy
css/styles.css        — все стили
js/main.js            — интерактив
assets/               — svg / png (экраны, блобы, иконки, паучки)
```

## ▶️ Запуск

Никакой сборки не нужно. Достаточно открыть `index.html` в браузере, либо поднять
локальный сервер:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

Типографика — [Manrope](https://fonts.google.com/specimen/Manrope) через Google Fonts.
